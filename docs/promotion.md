# 桌面搭子：X 首发与版本更新文案

## 名称与介绍

产品名称：**桌面搭子**。

一句话介绍：**帮你整理桌面、记下待办，到点提醒你喝水、起来动动。**

适用平台：Windows 10 / 11 x64。

宣传用实际操作说明用途：先用久坐超时后骨节逐节掉落的动画吸引注意，再展示桌面分类、添加待办和喝水记录。

## 首发主帖

搭配约 20 秒的真实操作演示发布，并将主帖置顶。加速计时演示须标注“超时效果加速演示”。

以下正文可直接使用：

```text
我把久坐提醒做成了「骨头一节节掉」。

桌面搭子：分类收纳、桌面待办、喝水提醒。
喝水超时，杯子还会溢水。

收纳保留原文件位置。
Windows 10/11 x64｜MIT 开源

下载：https://github.com/Gerson369/windows-desktop-widgets/releases/latest
```

### 首发自回复

```text
几个每天用得到的小地方：

· 应用、文件、图片、影音分开收纳
· 桌面直接记待办，安排日期和提醒
· 喝水计划可设目标、杯量和每杯时间
· 误点健康记录，15 秒内可撤销最近一次操作

日历、便签、倒数日、专注也能在助手里切换。

脊柱是计时动画，不检测真实坐姿或饮水。
```

## 后续版本发布

1. 先发布真实可下载的版本，并在 Release 页面记录版本号和变更。
2. 使用“引用帖 / Quote post”引用同一条首发帖，在新帖中说明本次更新。
3. 在首发线程下回复“版本号 + 一句变化 + 更新帖链接”，形成版本索引。
4. 小修复可合并说明；没有真实变化时不重复包装成新版。

普通转发不能附上更新文字；更新说明写在新的引用帖中，不依赖长期编辑原首发正文。每条引用帖的互动数据独立。

### 更新帖模板

替换方括号内容，保留本次最重要的 1—3 项变化；删除没有发生的项目。发布前在 X 编辑器复核长度。

```text
[一句话钩子：这次解决了什么具体麻烦]

桌面搭子 v[版本号] 已发布。

· [变化一：现在可以怎样操作]
· [变化二：少了什么麻烦]
· [变化三：修复了什么实际问题]

[一句真实的使用场景或效果]

下载：https://github.com/Gerson369/windows-desktop-widgets/releases/latest
```

## 真实宣传边界

- 分类收纳和拖入引用保留原文件位置；用户主动改名或移到回收站属于文件操作，不能宣传软件“绝不改动文件”。
- 喝水和活动提醒基于计时与手动记录，不能识别真实坐姿或饮水。
- 待办、便签和配置保存在本机；天气与在线日历需要联网。
- 日历支持 ICS 导入与 HTTPS 只读订阅，不宣传账号双向同步。
- 当前可访问的界面没有接入 AI 对话、全盘搜索、剪贴板或图片处理，不将遗留模块作为现有卖点。
- 不承诺固定资源占用或所有显卡、蓝牙、多屏环境兼容。
- 版本号以实际公开 Release 为准；未发布的本地版本不能写成“已发布”。已发布的 v2.4.0 安装包仍显示旧名「Gerson 桌面助手」。
